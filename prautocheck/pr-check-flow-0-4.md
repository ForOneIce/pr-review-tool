# Open PR 检查流程图（0-4）

```mermaid
flowchart TD
    T[定时任务触发或手动执行] --> T1[调用 run-precheck-hourly.ps1]
    T1 --> T2{网络错误?}
    T2 -- 是 --> T3[自动重试最多3次<br/>间隔30秒]
    T2 -- 否 --> A
    T3 --> A[获取 open PR 列表]

    A --> A0{筛选后 open PR 数量为 0?}
    A0 -- 是 --> END0[结束: 不输出报告, 不产生日志]
    A0 -- 否 --> A1[按 PR 序号从小到大逐条检查]

    A1 --> P00{pre-0: 删除多个主目录第一层文件夹?}
    P00 -- 是 --> O00[评论灾难改动提示 + Close]
    P00 -- 否 --> S0{0: 是否有新增 .sol 文件?}

    S0 -- 否 --> O01[评论缺少 .sol + Close]
    S0 -- 是 --> S05{0.5: 新增文件夹名含空格?}
    S05 -- 是 --> O05[评论空格命名问题 + Close]
    S05 -- 否 --> S1{1: 新增 .sol 命名检查}

    S1 -- 1-1-1 无 day --> O111[评论命名错误 + Close]
    S1 -- 1-2 通过 --> S2{2: 标题是否符合规则?}

    S2 -- 否 --> O21[自动改标题: 提交人{login} 挑战尝试闯关到DayN]
    S2 -- 是 --> S3
    O21 --> S3{3: 路径归属检查}

    S3 -- 3-1 根目录直提 --> O31[评论路径错误 + Close]
    S3 -- 3-2-1 触碰 bala --> O321[评论禁止改 bala + Close]
    S3 -- 3-2-2 触碰他人目录/多目录 --> O322[评论只改个人目录 + Close]
    S3 -- 3-2-3 通过 --> S4{4: 新增 .sol 可编译?}

    S4 -- 否 --> O41[评论具体不可编译文件 + Close]
    S4 -- 是 --> O42[标记: 待人工审核]

    O00 --> LATE{Week 超时判定?}
    O01 --> LATE
    O05 --> LATE
    O111 --> LATE
    O21 --> LATE
    O31 --> LATE
    O321 --> LATE
    O322 --> LATE
    O41 --> LATE
    O42 --> LATE

    LATE -- 是 --> WL[追加评论: 该周已超时<br/>当前仅评论, 未打 label]
    LATE -- 否 --> R
    WL --> R[输出 Excel 报告 + 执行摘要]

    R --> M{是否 --apply?}
    M -- 否 --> END1[预览模式结束]
    M -- 是 --> M1{命中动作数 = 0?}
    M1 -- 是 --> END2[结束: 无可执行动作]
    M1 -- 否 --> C{--yes 或人工确认?}

    C -- 否 --> END3[取消执行]
    C -- 是 --> E[执行动作: comment/retitle/close/merge]

    E --> WL{merge 成功且 week 超时?}
    WL -- 是 --> WLT[打标签: week1~week4-late + 超时评论]
    WL -- 否 --> W
    WLT --> W{merge 成功且日期=3月8日?}
    W -- 是 --> WC[追加评论: PR已成功提交！妇女节快乐~]
    W -- 否 --> E1
    WC --> E1[统计成功与失败]

    E1 --> F{存在失败项?}
    F -- 否 --> END4[结束: 输出执行结果]
    F -- 是 --> Y{--yes ?}
    Y -- 是 --> END5[结束: 保留失败项]
    Y -- 否 --> Q{是否重试失败项?}
    Q -- 是 --> E
    Q -- 否 --> END5
```
